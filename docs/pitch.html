RoboCombat BlackBox

An always-on AI robot test engineer that lives on the Dell Pro Max GB10 — continuously benchmarking humanoids, investigating failures, and filing shift reports. 100% local.

Illustrative simulation · not verified hardware performance

Problem

Humanoids are entering dangerous work. Evaluation is still manual.

  • Expert-scarce, sporadic regression testing
  • Hard to compare vendors with reproducible conditions
  • Cloud LLMs are a non-starter for IP-sensitive robot logs
  • Labs need a local, always-on test engineer — not another chat toy.

Product

BlackBox: the GB10 that never clocks out

Always-on

  • Regression sweep every 15 min
  • Heartbeat every 30 min
  • Severity-tagged shift reports

On demand

  • Operator chat → live experiment
  • Controlled one-variable follow-ups
  • Auto 3D replay of every run

Robots: Unitree G1 · BD Atlas · AgiBot A2 Ultra  |  Missions: Fire Rescue · Deep Mine

Architecture

Local-first by construction

Operator / Cron → OpenClaw —or— NemoClaw + OpenShell sandbox → Ollama gpt-oss:20b on GB10 GPU (no cloud keys) → robocombat-lab skill → /api/agent/* → Deterministic sim + 3D viz + reports

Sandbox policy: deny-by-default · only GET/POST /api/agent/** via curl
